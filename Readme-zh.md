# Notez —— 隐私优先的 AI 写作与知识激活空间

[English README](README.md)

官方网站： [notezapp.com](https://notezapp.com)  •  下载： [notezapp.com/download](https://notezapp.com/download)

Notez 是一个面向“严肃写作 / 深度内容生产”场景的本地优先写作与知识协同空间。它不是把你的文档整体上传到不透明云端再调用一个通用模型，而是在本地完成文档存储、解析、索引、向量、引用追踪，仅在需要生成或检索时，裁剪最小必要的上下文片段发送给外部模型。目标不是“一键全自动写完”，而是系统性降低：检索 → 草稿 → 引证核对 → 多轮扩展 的整体摩擦成本。

## 为什么是 Notez？

传统笔记 / 云文档 / 通用 AI 写作工具在以下严肃场景里集体失效：隐私风险、知识资产沉睡、输出浅层化、引用脆弱、风格与论证链漂移。Notez 针对四个核心支柱：

1. 隐私边界可信：本地优先存储与处理；外发上下文可预览。
2. 知识资产激活：文档被切分为语义片段并参与补全 / 对话 / 检索 / 引用。
3. 语义融合管线：检索 + 片段验证 + 约束生成 + 来源绑定，而不只是“调一次模型”。
4. 可追踪与一致性：生成段落可携带引用；固定关键观点用于后续一致性约束。

## 核心特性（概览）

- 本地知识库与索引（Markdown / PDF / Docx / Txt / 文件夹同步）
- AI 智能续写：结合你的材料进行上下文感知补全
- 上下文 AI 对话：多轮、@ 精准指向、引用溯源、置顶重要回复
- 智能检索与引用：一键查看来源与位置
- 文档导入流水线（解析 → 结构抽取 → 语义切块 → 向量嵌入 → 关键词索引）
- 导出 PDF / Word（保留结构）
- 私有 / 自定义模型配置（OpenAI / Azure / 自建 / 本地推理）
- 多语言界面与文档（中 / 英）

## 典型工作流速览

1. 导入或同步一批研究 / 法务 / 写作材料。
2. 配置至少一个对话模型与一个向量模型（如：`gpt-5` + `text-embedding-3-small`）。
3. 开始写作；自动补全提供语境续写建议。
4. 使用 AI Chat 搭配 @ 标签精准检索；置顶（Pin）确认过的结论。
5. 插入带引用的片段；核对来源；多轮迭代。
6. 导出最终稿为 PDF 或 Word。

## 隐私与数据处理理念

网站层仅用于展示与文档。实际 Notez 应用对用户文档的解析、索引、向量、引用绑定全在本地完成；调用外部模型时只发送裁剪过的最小相关片段，不上传完整文档。用户可自行部署或使用本地模型以获得更高控制权。
